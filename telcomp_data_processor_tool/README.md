# TELCOMP Data Processor Tool

This tool is designed for processing data using the TELCOMP (Teleprocessing Compiler) language. It serves as a utility for handling data operations within a TELCOMP environment.

## Features
- Basic data processing functions
- Configuration via `config.cfg`
- Modular design for extensibility

## Usage
- Place the main script `main.tlc` in the root of the tool folder.
- Use `config.cfg` to adjust settings as needed.
