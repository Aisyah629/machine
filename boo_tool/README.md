# Boo Tool

A dedicated folder and toolset for the Boo programming language.

## Overview

This tool is built strictly using the **Boo** programming language, a statically-typed, object-oriented language that compiles to .NET and shares strong syntactic similarities with Python. Boo was notably popular in the Unity game development community for its clean syntax and rapid prototyping capabilities.

## Purpose

The Boo Tool provides a structured environment for developing flexible object-oriented scripts, focusing on:
- Rapid game logic prototyping
- Unity-compatible gameplay systems
- Type-safe .NET interoperability
- Clean, readable syntax inspired by Python but with strong typing

## Structure

- `main.boo`: The core implementation file containing the primary logic and framework scaffolding.
- `README.md`: This documentation file.

## Usage

Compile the Boo source using the Boo Compiler (`boo`) and execute against the .NET runtime. This tool serves as both a language showcase and a functional template for object-oriented scripting workflows.

## Notes

- Boo targets .NET Framework / .NET Core.
- Strongly encouraged to use proper namespaces and class structures for maintainability.
- Ideal for developers transitioning from Python or C# who need a lightweight, expressive scripting language.
