# Easy PL/I Data Processor Tool

This tool provides a comprehensive data processing utility written in Easy PL/I. It demonstrates data ingestion, transformation, and output capabilities using the Easy PL/I programming language.

## Features

- **Data Ingestion**: Reads input data from standard input or files.
- **Data Transformation**: Processes and transforms data structures.
- **Output Generation**: Formats and outputs processed data.

## Usage

To use this tool, ensure you have an Easy PL/I compiler installed. Compile the main source file `main.pl` and run the executable.

## Dependencies

- Easy PL/I Compiler
