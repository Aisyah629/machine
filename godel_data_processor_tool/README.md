# Gödel Data Processor Tool

## Overview
This tool provides basic data processing capabilities using the Gödel programming language. It demonstrates parsing, filtering, and aggregation operations on structured data.

## Features
- **Data Parsing**: Converts string-based data into structured records.
- **Filtering**: Filters records based on specific criteria (e.g., category).
- **Aggregation**: Computes aggregate values (e.g., sum) from filtered datasets.

## Usage
1. Save the `main.gd` file in this directory.
2. Run using a Gödel compiler or interpreter.
3. Example command: `godel main.gd`
