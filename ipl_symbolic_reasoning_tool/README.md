# IPL Symbolic Reasoning Tool

## Overview
This tool implements a symbolic reasoning engine using IPL (Information Processing Language), one of the earliest programming languages designed for artificial intelligence. It demonstrates pattern matching, rule-based inference, and semantic network processing.

## Features
- IPL-based semantic network representation
- Pattern matching engine
- Rule-based inference system
- Traceable reasoning paths
- Interactive query interface

## Usage
The main program `main.ipl` serves as the entry point. Run it with the IPL interpreter to perform symbolic reasoning tasks.

## Files
- `main.ipl`: Core IPL code for symbolic reasoning
- `README.md`: Project documentation

## Note
IPL is a historical programming language. This tool is primarily educational, demonstrating early concepts in AI programming.
