# E Tool

## Overview
The `e_tool` is a dedicated development environment for building applications in the E programming language. E is a secure, object-capability programming language designed for distributed computing and concurrent applications.

## Features
- **Object Capability Security**: Enforces strict security boundaries by design.
- **Distributed Programming**: Native support for safe remote object communication.
- **Concurrency**: Robust model for handling concurrent tasks and distributed interactions.

## Usage
1. Navigate to the `e_tool` directory.
2. Use the E compiler/interpreter to run scripts.
3. Refer to E documentation for syntax and capability patterns.
