# Datalog Data Processing Engine Tool

This tool provides a declarative data processing engine implemented in Datalog.
It focuses on rule-based data transformation, validation, and query operations.

## Features
- Declarative rule definitions
- Relational data processing
- Built-in validation checks
- Extensible rule engine

## Usage
Load the main.dl file and provide input facts using the provided schema.

## Schema
- `fact/2`: Base fact representation.
- `rule/3`: Rule definition.
- `output/2`: Output collection.
