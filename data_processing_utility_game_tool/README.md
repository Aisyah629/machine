## Data Processing Utility

This utility provides foundational functions for data processing operations within the Game Maker Language environment. It includes functions for data manipulation, validation, and transformation suitable for game development contexts (e.g., handling player data, inventory systems, or save files).

### Features
- **Data Validation**: Check if input data meets expected formats.
- **Transformation**: Basic transformations on arrays and structs.
- **Serialization**: Simple JSON-like serialization for game data.

### Usage
Include this code in your project and call the provided functions as needed.

### Functions
- `data_process_utility_init()`: Initializes internal state.
- `validate_data(data, expected_type)`: Validates data type.
- `transform_data(data, operation)`: Applies a transformation.
