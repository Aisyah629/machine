# LC-3 Data Processor Tool

## Overview
This tool is a simple data processing utility written strictly in **LC-3** assembly language. It serves as a foundational example of how data transformation and manipulation can be implemented at the machine instruction level within the LC-3 architecture.

## Features
- **Data Ingestion**: Loads sample data into registers.
- **Transformation**: Applies a configurable offset to the input data.
- **Storage**: Saves the processed result back to memory.
- **Pure LC-3**: No external dependencies; runs on any standard LC-3 emulator.

## File Structure
- `main.asm`: The main assembly source code containing the processing logic.

## Usage
1. Save `main.asm` to your LC-3 working directory.
2. Load the code into an LC-3 emulator (e.g., LC3D, LC3Studio).
3. Assemble and run the program.
4. Check memory locations `x3010` (INPUT_VAL) and `x3011` (RESULT_VAL) for results.

## How It Works
1. The program initializes an `OFFSET` of 5.
2. It loads a `SAMPLE_DATA` value of 10 into Register 0.
3. It adds the offset to the sample data, resulting in 15.
4. The result is stored in memory for further inspection.
