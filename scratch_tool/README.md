# Scratch Tool

## Overview
The Scratch Tool is an interactive visual programming environment designed for educational purposes. It features block-based logic assembly and real-time simulation capabilities, allowing users to create scripts, animations, and simple programs using a drag-and-drop interface.

## Features
- **Block-Based Logic Assembly**: Intuitive drag-and-drop blocks for coding logic.
- **Real-Time Simulation**: Immediate visual feedback as scripts are constructed.
- **Educational Focus**: Designed to teach programming concepts in an engaging and accessible way.
- **Script Editor**: A dedicated space for editing and managing scripts.
- **Simulation Panel**: Displays the output and behavior of the constructed programs.

## Usage
1. Drag and drop code blocks from the palette to the script editor.
2. Connect blocks to form logical sequences.
3. Press the play button to simulate and observe the results in the simulation panel.

## Installation
No installation is required. The Scratch Tool is self-contained and can be run directly in a compatible Scratch environment.
