# Turbo C++ Legacy System Profiler Tool

## Description
This tool is a high-performance memory manager and interrupt handler analyzer optimized for 16-bit real-mode DOS environments. It is built strictly using Turbo C++ to provide robust runtime profiling and debugging capabilities for legacy applications compiled with Borland compilers.

## Features
- Real-time memory allocation tracking for far/near pointers
- Interrupt vector table analysis and hooking capabilities
- CPU cycle counting and execution profiling
- Legacy DOS memory model support (Tiny, Small, Medium, Compact, Large, Huge)

## Requirements
- Turbo C++ 3.0 or later
- MS-DOS or DOS-compatible environment

## Usage
Compile the source file using the Turbo C++ compiler and run the resulting executable in a DOS environment to begin profiling.
