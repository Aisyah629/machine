# GameMonkey Script Simulation Engine

## Description
This tool implements a dynamic game simulation engine using GameMonkey Script (GMS). It demonstrates the use of GMS for entity management, event handling, and simulation logic.

## Features
- Entity-Component-System (ECS) pattern implementation
- Event-driven architecture
- Simulation loop management
- Entity serialization and deserialization

## Usage
To run the simulation engine, execute the following command:
```
gm -s main.gms
```

## File Structure
- `main.gms`: Main entry point for the simulation engine
- `sim.gms`: Core simulation logic
- `entity.gms`: Entity and component definitions
- `event.gms`: Event system implementation

## Dependencies
- GameMonkey Script Interpreter
