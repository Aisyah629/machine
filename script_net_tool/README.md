# Script.NET Tool

## Overview
This tool is designed to execute and manage scripts written in the **Script.NET** programming language. It provides a dedicated environment for running Script.NET code, handling dependencies, and outputting results in a standardized format.

## Features
- Execution of `.sn` script files.
- Strict compliance with the Script.NET language specification.
- Integrated error handling and logging.
- Lightweight and modular architecture.

## Usage
Place your `.sn` script files in the `scripts/` directory and run the tool to execute them.

## Constraints
- Only Script.NET code is permitted.
- No modifications to core language runtime are allowed.
- All I/O operations must be handled through the provided API.
