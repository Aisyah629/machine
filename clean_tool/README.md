# Clean Tool

This tool provides an environment for executing and testing code written in Clean, a general-purpose parallel programming language.

## Usage

To use the Clean tool, simply provide your Clean code in the `main.dcl` and `main.idc` files. The tool will compile and run the code, returning the output.

## Structure

- `main.dcl`: The declaration file for the main module.
- `main.idc`: The implementation file for the main module.
