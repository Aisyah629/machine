# Subtext Interactive Documentation Tool

## Overview
This tool parses source code comments, constructs hierarchical knowledge graphs, and outputs navigable web-based manuals. It is built STRICTLY using the Subtext programming language.

## Features
- Automated source code comment parsing
- Hierarchical knowledge graph construction
- Web-based navigable manual generation
- Subtext-native implementation

## Usage
Run the main Subtext script to initiate the documentation generation pipeline.
