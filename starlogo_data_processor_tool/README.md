# StarLogo Data Processor Tool

This tool provides data processing utilities using the StarLogo programming environment.

## Features
- Data ingestion from simulated agent populations.
- Statistical analysis of agent states.
- Data transformation and aggregation.

## Usage
Import this tool into your StarLogo NG project to access advanced data processing capabilities.

## File Structure
- `starlogo_data_processor_tool.starlogo`: Main code file.
