# Pawn Tool

## Description
A dedicated tool for generating, testing, and managing Pawn programming language scripts and projects.

## Features
- Syntax highlighting and validation
- Automated compilation checks
- Code formatting and linting
- Integration with PAWN compiler (pawncc)

## Usage

### Installation
1. Clone the repository.
2. Ensure `pawncc` (Pawn compiler) is installed in your system PATH.

### Running the Tool
```bash
./pawn_tool/main.pawn
```

## Project Structure
- `README.md`: This file.
- `main.pawn`: The core Pawn script implementation.

## Supported Pawn Versions
- SA:MP 0.3.7
- OpenKore
- Generic ANSI C Pawn
