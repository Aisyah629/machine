# Legoscript Data Processing Tool

This tool is designed for data processing tasks using Legoscript. It provides utilities for loading, transforming, and analyzing structured data sets. It leverages Legoscript's array manipulation capabilities to process datasets efficiently.

## Features
- Load structured data (simulated JSON-like objects)
- Filter records based on conditions
- Transform data fields
- Generate basic statistics

## Usage
Run the main.lego file to execute the default data processing pipeline.
