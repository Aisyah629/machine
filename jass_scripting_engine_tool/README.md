# JASS Scripting Engine Tool

## Description
A strict syntax and logic validator for Warcraft III map scripting (JASS). This tool is designed to parse, analyze, and validate JASS code to ensure compliance with language standards and best practices.

## Features
- JASS Syntax Validation
- Logic Flow Analysis
- Variable and Function Declaration Checking
- Error Reporting with Line Numbers
- Optimized Code Structure Recommendations

## Usage
To run the validator, execute the following command:

```bash
./jass_scripting_engine_tool/main.jass <input_file.j>
```

## Architecture
- **main.jass**: Entry point for the JASS validation engine.
- **README.md**: Project documentation and usage guide.
