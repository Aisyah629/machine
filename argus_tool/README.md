# Argus Tool

A tool implemented in the Argus programming language, focusing on distributed secure object systems with robust exception handling and access control.

## Features

- Distributed object model
- Security and access control mechanisms
- Robust error handling
- Reliable message passing

## Usage

To use this tool, compile the `main.arg` file using an Argus compiler and run the resulting executable.

## Installation

1. Install an Argus compiler.
2. Clone this repository.
3. Navigate to the `argus_tool` directory.
4. Compile the code: `argus main.arg`
5. Run the program: `./a.out`
