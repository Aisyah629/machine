# Lingo Tool

## Description
This tool implements a custom solution strictly using the Lingo programming language. It demonstrates core language features including object-oriented concepts, scene management, and multimedia handling characteristic of Lingo (ActionScript derivative used for Director/Flash).

## Features
- Pure Lingo implementation
- Object-oriented scripting
- Scene and movie control
- Interactive media handling
- Optimized for legacy Director environments

## Usage
Place the `main.lgo` script in your Lingo script library. Initialize the movie or scene to begin execution.

## Architecture
- `main.lgo`: Entry point containing all core logic and object definitions.
- No external dependencies; fully self-contained within the Lingo environment.
