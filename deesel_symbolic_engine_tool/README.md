# Deesel Symbolic Engine Tool

## Overview
The Deesel Symbolic Engine Tool is a high-performance utility built strictly in **Deesel**. It is designed for advanced symbolic computation, automated analysis, and mathematical expression evaluation.

## Features
- Recursive mathematical functions (factorial, fibonacci)
- Symbolic differentiation engine
- Expression evaluation with variable substitution
- Automated analysis pipelines

## Installation
Ensure you have the Deesel compiler installed. Clone this repository and navigate to the tool directory:
```bash
cd deesel_symbolic_engine_tool
```

## Usage
Execute the main Deesel script:
```bash
deesel main.deesel
```

## Architecture
- `main.deesel`: Core logic and execution entry point
- No external dependencies required
