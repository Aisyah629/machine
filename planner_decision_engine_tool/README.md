# Planner Decision Engine Tool

This tool is a specialized Decision Engine implementation built using the **Planner** programming language.

## Overview
Planner is a programming language that supports forward and backward chaining, and allows for the definition of procedures and assertions. This tool leverages these capabilities to create a robust decision-making system.

## Features
- Forward and backward chaining logic.
- Procedural abstraction for complex decision paths.
- Robust assertion handling.
- Configurable decision rules.

## Usage
Run the tool using the Planner interpreter:
```bash
planner main.pln
```

## Project Structure
- `main.pln`: The main logic and decision engine code.
- `README.md`: This file.
