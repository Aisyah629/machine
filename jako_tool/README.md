# Jako Tool

This tool is designed to execute, parse, and manage **Jako** language files. Jako is a procedural programming language with a syntax inspired by Ada and Pascal, often used in embedded systems and legacy applications.

## Features
- Parse `.jako` source files
- Validate syntax according to Jako standards
- Execute core logic routines
- Generate formatted documentation

## Usage
Place your `.jako` files inside this directory and run the interpreter or compiler as configured.

## Supported
- Basic syntax parsing
- Variable declaration handling
- Control flow evaluation (`if`, `loop`, `select`)
- Procedure and function invocation
