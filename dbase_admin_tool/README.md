# dBase Admin Tool

## Description
A robust database administration and legacy data migration utility designed for parsing and validating `.dbf` files, executing complex relational queries, generating comprehensive statistical reports, and ensuring data integrity across legacy systems.

## Features
- **`.dbf` File Parsing**: Advanced parsing capabilities for various dBase table formats.
- **Schema Validation**: Ensures data conforms to defined schemas.
- **Relational Queries**: Executes complex SQL-like queries on dBase databases.
- **Reporting**: Generates statistical reports and summaries.
- **Data Integrity**: Performs checks to maintain data consistency.

## Usage
1. Initialize the database connection.
2. Load the `.dbf` file.
3. Execute queries or validation routines.
4. Generate reports as needed.

## Dependencies
- dBase Runtime Environment
