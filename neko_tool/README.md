# Neko Tool

## Description

This tool is built strictly using the Neko programming language. It is designed to demonstrate the capabilities of Neko within this workspace.

## Features

- Pure Neko implementation
- Modular design
- Easy to extend

## Usage

To run the tool, ensure you have [Neko](https://nekovm.org/) installed. Then execute the following command in the `neko_tool` directory:

```bash
nekoc main.ne
nekoc run main
```
