# Mesa Tool

## Description
This tool implements a concurrent process scheduling system with cooperative multitasking and inter-process communication primitives, built strictly using the **Mesa** programming language.

## Objective
Design and implement a distributed task queue with cooperative concurrency and message passing synchronization, leveraging Mesa's class and monitor features for thread safety and process coordination.

## Features
- Cooperative multitasking scheduler
- Monitor-based synchronization primitives
- Inter-process communication via message queues
- Fault-tolerant process state management
- Clean separation of concurrency logic and application domain

## Usage
Compile and execute the Mesa source code using a Mesa-compatible compiler or interpreter. Ensure all monitor classes are properly instantiated and message channels are initialized before launching concurrent tasks.
