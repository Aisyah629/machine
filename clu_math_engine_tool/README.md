# CLU Mathematical Engine Tool

## Description
A functional tool written in CLU implementing a cryptographic prime generator and a numerical integration engine using the Trapezoidal Rule.

## Features
- **Prime Sieve**: Implements the Sieve of Eratosthenes to find all prime numbers up to a given limit.
- **Numerical Integration**: Calculates the definite integral of a polynomial (specifically $x^2 + 1$) between two bounds.
- **Procedural Abstraction**: Demonstrates CLU's unique design with `iter` and `proc` constructs.

## Usage
1. Compile the `main.clu` file using a standard CLU compiler.
2. Run the executable to generate primes up to 50 and compute the integral from 0 to 10.

## Dependencies
- Standard CLU Compiler Environment
