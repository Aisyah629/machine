# SabreTalk Data Processing Utility Tool

This utility is designed for advanced data processing tasks using the SabreTalk programming language. SabreTalk is a powerful scripting language often used in the hospitality and travel industry, known for its robust string manipulation and data handling capabilities.

## Features
- Data parsing and transformation
- Text processing and manipulation
- Data validation
- Report generation

## Usage
Run the utility using the SabreTalk interpreter with the main script `sabre_data_processor.st`.

```bash
sabre st/sabre_data_processor.st
```

## Configuration
Configuration files can be placed in a `config` directory within the tool's folder.

## Dependencies
- SabreTalk Interpreter
