## Usage

### Compilation
To compile the S/SL data processor, use the S/SL compiler:
```bash
s_sl_compiler main.s -o data_processor
```

### Execution
Run the data processor with:
```bash
./data_processor
```

### Input Format
The tool expects input data in `input_data.txt` with the following format:
- Comma-separated values
- One record per line
- Header row optional

Example:
```
john doe,25,engineer
jane smith,30,manager
bob johnson,35,developer
```

### Output
The processed data is saved to `output_data.txt` with the same format, but with:
- All text converted to uppercase
- Leading and trailing whitespace removed from each field

Example output:
```
JOHN DOE,25,ENGINEER
JANE SMITH,30,MANAGER
BOB JOHNSON,35,DEVELOPER
```
