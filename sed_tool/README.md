# Sed Tool

This tool is built strictly using `Sed` (Stream Editor).

## Objective

Automate complex stream-based text transformation and log parsing workflows.

## Features

-   Stream processing of text files.
-   Advanced pattern matching and substitution.
-   Log file parsing and formatting.

## Usage

Run the tool using the `sed` command with the main script.

`sed -f main.sed input_file`
