# PCASTL Tool

This is the dedicated folder for the PCASTL tool.

## Description

This tool implements a parallel computation module using the PCASTL programming language. It is designed to handle complex parallel tasks efficiently.

## Usage

To use this tool, place the `main.pcastl` file in the root directory and run it using the PCASTL interpreter.

## Structure

- `README.md`: This file, containing documentation about the tool.
- `main.pcastl`: The main source code file for the PCASTL tool.
