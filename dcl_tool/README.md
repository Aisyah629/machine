# DCL Automated System Configuration Tool

This tool provides automated system configuration and batch processing capabilities using DEC Command Language (DCL) for OpenVMS systems. It includes utilities for directory management, file indexing, and system parameter adjustments.

## Features

- Directory creation and management
- File indexing and cataloging
- Batch job submission and monitoring
- System parameter configuration

## Usage

Execute the following command to start the tool:

```dcl
$ @SYS$DISK:[TOOL_DIR]dcl_tool.com
```

## Configuration

Customize the configuration by editing the `config.dat` file in the same directory.
