# AIMMS Data Processor Tool

This tool is designed for advanced data processing within the AIMMS ecosystem.
It provides utilities for data ingestion, transformation, and optimization
preparation.

## Features
- Data ingestion from various sources
- Data transformation pipelines
- Preparation for optimization models

## Usage
To use this tool, initialize the `aimms_new_data_processor_tool` project in the
AIMMS IDE.

## Requirements
- AIMMS 4.x
