# Prolog Diagnostic Tool

A robust Prolog-based diagnostic system for automated code analysis and bug detection.

## Features
- Automated syntax and semantic analysis
- Bug pattern matching and detection
- Rule-based diagnostics
- Extensible knowledge base

## Usage
Run the Prolog interpreter and load `main.pl`:
```prolog
?- [main].
?- diagnose(file_path).
```

## Rules
- All logic must be implemented in Prolog.
- Maintain strict adherence to the diagnostic objectives.
