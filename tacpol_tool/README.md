# TACPOL Tool

A lightweight implementation of the TACPOL (Tiny Assembly-based Computation Protocol for Logic) language.

## Description
This tool provides a runtime and compiler for TACPOL, a minimalist stack-based programming language designed for educational purposes and lightweight computation.

## Features
- Stack-based execution model
- Minimal instruction set (PUSH, POP, JZ, JMP, SUB, HALT, etc.)
- Simple assembly-like syntax
- Educational focus on low-level computation concepts

## Usage
Compile and run TACPOL source files using the provided interpreter.
