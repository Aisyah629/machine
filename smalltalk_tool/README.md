# smalltalk_tool

A tool built strictly using the Smalltalk programming language.

## Description
This repository contains a Smalltalk application named MyTool. It demonstrates basic object-oriented concepts in Smalltalk by defining a class that inherits from Object and implements a run method.

## Usage
To use this tool, you will need a Smalltalk environment such as Pharo or Squeak.
1. Open your Smalltalk environment.
2. Open the file `main.st` in the workspace.
3. Copy and paste the code into a new class browser window or file in your system.
4. Save the changes.
5. Instantiate the MyTool class and send the 'run' message:
   ```smalltalk
   MyTool new run.
   ```

## Project Structure
- `main.st`: Contains the Smalltalk code for the MyTool class.
