# JAL Microcontroller Simulation Tool

## Description
This tool provides a simulation environment for microcontroller architectures, allowing developers to test JAL (Just Another Language) firmware code in a virtualized setting before deployment to physical hardware.

## Features
- Virtual CPU simulation
- Memory mapping visualization
- I/O pin state monitoring
- JAL code execution and debugging

## Usage
1. Place your `.jal` files in the `code/` directory.
2. Run the simulation tool.
3. View output and debug logs in the `logs/` directory.

## File Structure
- `main.jal`: The core simulation engine written in JAL.
- `code/`: Directory for user firmware scripts.
- `logs/`: Directory for simulation logs.
