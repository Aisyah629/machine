# VBScript System Admin Tool

A comprehensive Windows system administration framework designed to manage Active Directory objects, user profiles, and system configurations using VBScript.

## Features
- User Account Management
- Active Directory Object Manipulation
- Registry Tweaks Automation
- System Service Control
- Event Log Monitoring

## Prerequisites
- Windows OS (Server or Client)
- Administrator Privileges
- VBScript Engine (cscript.exe)

## Usage
Run the main script with administrative privileges:
cscript main.vbs
