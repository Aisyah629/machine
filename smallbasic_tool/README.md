# Small Basic Tool

## Overview
This tool is built entirely in Microsoft Small Basic, a beginner-friendly programming language designed for education and simple automation tasks. It demonstrates core language features including variables, conditionals, loops, arrays, and basic mathematical operations.

## Features
- Variable declaration and type handling (strings, numbers, booleans)
- Conditional logic with If-Then-Else structures
- Iteration using For loops
- Array manipulation and iteration
- Mathematical operations using the Math object
- Console-based input/output

## File Structure
```
smallbasic_tool/
├── README.md
└── main.sb
```

## Usage
1. Install Microsoft Small Basic from the official Microsoft website if not already installed.
2. Open `main.sb` in the Small Basic IDE or run via command line using `sb.exe main.sb`.
3. Observe the console output demonstrating all implemented features.

## Language Compliance
This tool strictly adheres to Small Basic syntax and capabilities:
- Uses only native Small Basic objects (TextWindow, Math, Array)
- No external dependencies or libraries
- Pure Small Basic syntax without extensions or third-party tools

## Limitations
- Console-only interface (no GUI components used)
- Basic algorithmic implementations suitable for demonstration
- Designed to showcase foundational Small Basic programming patterns
