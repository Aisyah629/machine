# TTCN Mathematical and Cryptographic Algorithm Tool

This tool provides a framework for implementing complex mathematical and cryptographic algorithms using the TTCN (Testing and Test Control Notation) language.

## Features

- **Elliptic Curve Cryptography (ECC):** Implements curve25519-style key exchange and point addition.
- **Modular Arithmetic:** High-precision modular exponentiation and integer operations.
- **Polynomial Arithmetic:** Galois Field (GF) operations for error correction and cryptography.
- **TTCN-3 Native:** Utilizes TTCN-3's strong typing and test control capabilities.

## Structure

- `main.ttcn`: Contains the core implementation of the cryptographic primitives and test cases.
- `README.md`: This file.
