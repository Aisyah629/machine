# notc_tool

## Description
The `notc_tool` is a dedicated development environment built strictly using the **Not eXactly C** programming language. This tool is designed for low-level systems programming, emphasizing manual memory management and hardware abstraction layers.

## Features
- **Manual Memory Management**: Precise control over allocation and deallocation.
- **Hardware Abstraction**: Low-level access to hardware components.
- **Strict Compliance**: Adheres strictly to the "Not eXactly C" language specification.

## Structure
- `main.nex`: The primary entry point and core logic for the tool.

## Usage
To use the `notc_tool`, navigate to the `notc_tool` directory and compile/run the `main.nex` file using the appropriate Not eXactly C compiler or interpreter.
