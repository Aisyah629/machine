# MIIS Identity Engine Tool

## Description
The MIIS Identity Engine Tool is a specialized utility built with MIIS (Microsoft Identity Integration Server) scripting logic to manage, synchronize, and audit identity data across enterprise directories.

## Features
- **Identity Synchronization**: Bi-directional sync between AD, Exchange, and other HR systems.
- **Attribute Mapping**: Flexible mapping configurations for user attributes.
- **Provisioning Engine**: Automated account creation and modification workflows.
- **Audit Logging**: Detailed logging of all sync and provision operations.

## Usage
1. Install the MIIS runtime.
2. Place your MA (Management Agent) configuration files in the `config/` directory.
3. Run the engine tool to initiate sync cycles.
