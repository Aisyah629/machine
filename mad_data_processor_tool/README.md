# MAD Data Processor Tool

## Overview
This utility is designed for data processing tasks using the MAD (Michigan Algorithm Decoder) programming language.
MAD was a general-purpose programming language created in the mid-1950s at the University of Michigan, one of the first high-level languages to be successfully implemented.

## Features
- Reads and processes structured data.
- Performs mathematical operations on data sets.
- Outputs processed results.

## Usage
1. Save the `main.mad` file in this directory.
2. Compile using a MAD compiler (e.g., MAD/360 or MAD X).
3. Run the executable.
