# HyperTalk Data Processing Tool

This utility demonstrates data processing capabilities using the HyperTalk scripting language, native to HyperCard.

## Features
- Line-based text processing
- Word counting
- Case normalization (uppercase conversion)
- File I/O operations

## Usage
1. Ensure `data_input.txt` exists in the same directory.
2. Run the `startProcessing` command.
3. View results in the output console.

## File Structure
- `main.hypertalk`: Contains the core processing logic.
- `data_input.txt`: Sample input file (create this manually for testing).

## Notes
- This script requires a HyperCard-compatible environment to execute.
- Error handling is included for file access.
