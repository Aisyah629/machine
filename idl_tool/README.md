# IDL Tool

This tool is a high-performance scientific data visualization and analysis engine built strictly using IDL (Interactive Data Language). It features interactive plotting capabilities and seamless integration with diverse data acquisition protocols.

## Features

- **Data Visualization**: Advanced 2D and 3D plotting.
- **Data Analysis**: Statistical analysis and signal processing.
- **Integration**: Support for various data formats and acquisition protocols.

## Usage

To run the tool, execute the main.idl script in an IDL environment.
