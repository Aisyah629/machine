# NASM Tool

This tool is a low-level system utility implemented using the Netwide Assembler (NASM) language.

## Description

The tool provides a simulation or implementation of a bootloader or system-level utility, demonstrating low-level programming concepts using x86 assembly.

## Usage

Compile the assembly code using NASM and link it with a linker like ld, or execute it in an emulator like QEMU.

## File Structure

- `main.asm`: The main assembly source code.
