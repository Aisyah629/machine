# CMS-2 Data Processing Tool

This tool is designed to perform data processing tasks using the CMS-2 programming language, which is specifically tailored for aerospace and defense applications.

## Features

- Data ingestion from flat files
- Data transformation and validation
- Output generation in various formats
- Error handling and logging

## Usage

To use this tool, ensure that you have the CMS-2 compiler installed on your system. You can then compile and run the main program file as follows:

```bash
cmsc main.cms2
./a.out
```
