# RPL Data Processing Tool

This tool provides utility functions for data processing using Reverse Polish Lisp (RPL), specifically designed for HP calculators or RPL emulators.

## Features
- List manipulation
- Data transformation
- Statistical calculations
- Text processing

## Usage
Load the RPL program into your RPL environment and execute the main entry point:

`
` -> RUN

## Modules
- `main.rpl`: Main data processing logic
- `data_utils.rpl`: Utility functions for data handling
- `stats.rpl`: Statistical analysis functions
