# CHR Data Processing Tool

A lightweight data processing utility written in Constraint Handling Rules (CHR).

## Overview
This tool demonstrates how CHR can be utilized for declarative data transformation, filtering, and cleaning tasks by defining constraint rules over data tuples.

## Features
- Declarative data transformation rules
- Filtering based on constraints
- Data validation via constraint propagation

## Usage
Run the CHR program with your data file using a CHR implementation (e.g., `chr` or a specific language extension).
