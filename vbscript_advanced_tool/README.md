# VBScript Advanced Tool

## Overview
This tool provides advanced file system organization and batch processing utilities using VBScript. It is designed to handle complex file manipulation tasks, directory structures, and batch operations efficiently within the Windows environment.

## Features
- **File Organization**: Automatically sort files based on extensions, dates, or custom criteria.
- **Batch Processing**: Execute multiple file operations in a single run.
- **Directory Management**: Create, rename, and manage directory structures.
- **Error Handling**: Robust error handling to ensure smooth execution even when errors occur.
- **Logging**: Detailed logging of operations for auditing and troubleshooting.

## Usage
1. **Run the Script**: Execute the `main.vbs` script using the Windows Script Host (cscript.exe or wscript.exe).
2. **Configuration**: Modify the configuration parameters within the script to suit your needs.
3. **Output**: Check the log file for detailed operation records.

## Dependencies
- Windows operating system
- Windows Script Host (WSH)
