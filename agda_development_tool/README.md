# Agda Development Tool

A comprehensive toolchain and utility suite for developing, compiling, and verifying Agda programs.

## Features
- Automatic dependency resolution
- Interactive type checking and theorem proving assistance
- Integration with standard Agda libraries
- Performance profiling for large formalizations
- Seamless export to LaTeX and HTML documentation

## Usage
Initialize the project and run the development environment using the standard Agda tools and this custom wrapper.
