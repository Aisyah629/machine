# SAS Statistical Analysis Tool

This tool is designed to perform advanced statistical analysis using SAS (Statistical Analysis System). It provides a comprehensive suite of functions for data manipulation, statistical testing, and data visualization.

## Features
- Data cleaning and preprocessing
- Descriptive statistics
- Inferential statistics (t-tests, ANOVA, chi-square)
- Regression analysis
- Time series analysis
- Custom macro development for complex analysis workflows

## Getting Started
To use this tool, ensure you have a SAS environment installed. Copy the provided `main.sas` file into your SAS workspace and execute it.

## Usage
```sas
%include 'path/to/main.sas';
%run_analysis(data_set=mydata, analysis_type=regression);
```
