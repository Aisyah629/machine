# LC-3 Tool

This directory contains an LC-3 program demonstrating bit manipulation and low-level system simulation.

## Objective
Implement an LC-3 program for efficient bit manipulation and low-level system simulation.

## Features
- Set, clear, and toggle specific bits in a register.
- Perform shift left and shift right operations.
- Simulate basic arithmetic operations using bit manipulation.

## Usage
1. Assemble the code using an LC-3 assembler.
2. Load the object code into the LC-3 memory.
3. Execute the program.

## Files
- `main.lc3`: The main LC-3 assembly program.
