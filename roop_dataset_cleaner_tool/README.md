# ROOP Dataset Cleaning and Text Formatting Tool

## Overview
This tool implements a robust pipeline for cleaning raw datasets and formatting text data using the ROOP programming language.

## Features
- **Duplicate Detection**: Automatically identifies and removes exact duplicate rows based on specified keys.
- **Null/Empty Handling**: Configurable handling of null, empty, or whitespace-only entries.
- **Case Normalization**: Standardizes text casing (lower/upper/title).
- **Whitespace Stripping**: Removes leading and trailing whitespace from string fields.
- **Output Formatting**: Exports cleaned data to standard delimited text files.

## Usage
Compile the tool and run it against your target CSV or text files.

```bash
roop main.roop
```
