# Pict Advanced Tool

## Description
The Pict Advanced Tool is a sophisticated pure functional image description and generation engine built using the Pict programming language. It leverages Pict's declarative syntax for defining geometric transformations, color blending, and layered image composition.

## Features
- **Pure Functional Paradigm**: Utilizes Pict's immutable data structures and functional composition for predictable image rendering.
- **Geometric Transformations**: Supports rotation, scaling, and translation of shapes.
- **Color Blending & Gradients**: Implements custom color palettes and gradient functions.
- **Layered Composition**: Allows overlaying multiple transformed shapes with distinct colors.
- **Canvas Management**: Configurable canvas size and centering logic.

## Getting Started
1. Ensure the Pict interpreter/compiler is installed.
2. Navigate to this directory.
3. Run the main script:
   ```bash
   pict main.pict
   ```
4. The tool will generate a canvas with a layered geometric composition.

## File Structure
- `main.pict`: Contains the core image generation logic, including shape definitions, transformations, color functions, and composition.

## Language
- **Pict**: A purely functional programming language designed for describing images.
