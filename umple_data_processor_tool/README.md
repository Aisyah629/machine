# Umple Data Processor Tool

## Overview
This is a data processing utility built using Umple, a model-driven engineering tool that combines object-oriented and relational features. It focuses on data transformation, validation, and extraction from various input sources.

## Features
- Data Validation
- Data Transformation
- Schema Definition
- Data Export

## Usage
1. Define your data schema in a .umple file.
2. Compile the Umple model to generate Java code.
3. Run the generated Java classes to process your data.

## Directory Structure
- `README.md`: This file.
- `main.ump`: The Umple model definition.
- `umple_output/`: Directory for generated Java code.
