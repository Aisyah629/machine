# Cyclone Tool

This tool is designed for working with Cyclone, a programming language extension for C that provides safe memory management and pointer safety.

## Features
- Parses and analyzes Cyclone source code.
- Provides utilities for syntax highlighting and error detection.
- Supports integration with IDEs and build systems.

## Installation
1. Clone the repository.
2. Ensure you have a Cyclone compiler installed.
3. Build the tool using the provided Makefile.
