# Neko Data Processor Tool

## Overview
This tool is designed for efficient data processing tasks using the Neko programming language. Neko is a fast, lightweight virtual machine and language suitable for scripting and data manipulation.

## Features
- Load and parse data from JSON files
- Process data records using defined functions
- Save processed data back to JSON or text formats
- Simple and modular architecture

## Usage
To run the tool, you need the Neko Virtual Machine. You can compile and run it as follows:

1. Save the `main.neko` file in the `neko_data_processor_tool` directory.
2. Open a terminal and navigate to the directory.
3. Compile the Neko script:
   ```sh
   neko compile main.neko
   ```
4. Run the compiled script:
   ```sh
   neko main.n
   ```

## Dependencies
- [NekoVM](http://nekovm.org/)
