# Data Processing Utility Main Tool

## Overview
This tool provides a comprehensive suite for data processing, featuring robust data transformation, validation, and cleaning capabilities. It is designed to handle various data formats and apply configurable rules to prepare datasets for analysis or further processing.

## Features
- **Data Transformation**: Apply custom mapping and transformation rules to data fields.
- **Validation**: Validate data against defined schemas and constraints.
- **Cleaning**: Remove duplicates, handle missing values, and format data consistently.
- **Extensible**: Modular design allows for easy addition of new processing steps.

## Usage
To execute the main tool, run the following command:

```bash
./main.py
```

## Configuration
Edit `config.json` to define your processing pipeline, including input sources, transformation rules, validation schemas, and output destinations.
