# ESPOL Tool

## Description
This tool implements a formal process specification engine designed for verifying concurrent system behaviors. It focuses on rigorous syntax validation of executable specifications, ensuring that process definitions adhere to strict logical constraints required for concurrency verification.

## Objective
Implement a formal process specification engine for verifying concurrent system behaviors with rigorous syntax validation.

## Usage
To use this tool, invoke the main execution script located in this directory. The engine will parse the provided ESPOL specifications, validate their syntax against the formal grammar, and perform initial consistency checks on the defined concurrent processes.

## File Structure
- `README.md`: This file.
- `main.espol`: The core implementation of the process specification engine.
