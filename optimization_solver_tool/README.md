# AMPL Optimization Solver Tool

## Overview
This tool is a dedicated mathematical optimization framework built strictly using the AMPL (A Mathematical Programming Language) programming language. It is designed to solve large-scale linear programming problems, non-linear programming, and mixed-integer optimization tasks efficiently.

## Features
- **Linear Programming (LP):** Solves large-scale LP problems with thousands of variables and constraints.
- **Sensitivity Analysis:** Generates comprehensive sensitivity reports to analyze the impact of changes in coefficients, right-hand sides, and objective functions.
- **Model Generation:** Automates the creation of `.mod` and `.dat` files for rapid problem definition.
- **Solver Integration:** Seamlessly connects with industry-standard solvers like CPLEX, Gurobi, and SCIP.

## Usage
1. Place your problem data in a `.dat` file.
2. Define your optimization model in a `.mod` file.
3. Run the solver via the command line or API integration.

## Requirements
- AMPL (A Mathematical Programming Language)
- Compatible optimization solver (CPLEX, Gurobi, SCIP, etc.)
