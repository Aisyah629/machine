# Drakon Tool

This is a new dedicated folder for the Drakon tool.

## Purpose

The Drakon tool is designed to generate code strictly using the **DRAKON** programming language.

## Features

- Strict adherence to the DRAKON syntax and semantics.
- Automated generation of .drakon files from high-level descriptions.
- Integration with existing Drakon editors and IDEs.

## Usage

To use this tool, provide your high-level logic or flowchart description, and the tool will generate the corresponding DRAKON code.
