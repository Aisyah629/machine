# Goo Tool

## Description
This tool provides a functional environment for writing, compiling, and running code in the Goo programming language. Goo is a dynamic, interpreted language known for its simplicity and ease of use, particularly suited for scripting and rapid prototyping.

## Features
- **Dynamic Typing**: Goo supports dynamic typing, allowing variables to change types at runtime.
- **Simplicity**: The language features a simple syntax, making it easy to learn and use.
- **Rich Standard Library**: Comes with a comprehensive standard library for common programming tasks.
- **Scripting Capabilities**: Ideal for writing scripts to automate tasks.

## Usage
To use the Goo tool, you can write your code in a `.goo` file and execute it using the provided interpreter. The tool also provides utilities for syntax checking and code formatting.

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/goo_tool.git
   ```
2. Navigate to the project directory:
   ```bash
   cd goo_tool
   ```
3. Install dependencies (if any):
   ```bash
   npm install
   ```

Here is a simple example of a Goo program:

print("Hello, World!")
