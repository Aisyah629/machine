# MillScript Tool

## Overview
The MillScript Tool is a specialized utility designed for high-performance text analysis, data transformation, and normalization. Built strictly with the syntax and capabilities of MillScript, this tool serves as a lightweight yet powerful engine for processing structured and unstructured text data.

## Features
- **Text Parsing**: Advanced tokenization and lexical analysis.
- **Data Normalization**: Standardizes data formats (dates, numbers, strings).
- **Pattern Matching**: Regular expression support with optimized execution.
- **Transform Logic**: Apply custom transformation rules to data streams.

## Usage
To execute the MillScript Tool, navigate to the `millscript_tool` directory and run the main script:

```bash
millscript main.ms
```

## Files
- `main.ms`: The core MillScript program implementing the analysis and normalization logic.
