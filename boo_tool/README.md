# boo_tool

## Overview
The `boo_tool` is an advanced scripting and code generation framework for .NET applications. Built strictly in the Boo programming language, this tool emphasizes metaprogramming, compiler design, and dynamic object manipulation.

## Features
- **Metaprogramming**: Leverage Boo's powerful AST manipulation capabilities to generate and modify code dynamically.
- **Compiler Design**: Explore Boo's compiler structure to build domain-specific languages (DSLs) and custom compilers.
- **Dynamic Object Manipulation**: Utilize Boo's `dynamic` keyword and duck typing to interact with dynamic objects seamlessly.
- **Scripting**: Execute Boo scripts directly or embed them within .NET applications for flexible behavior.

## Usage
1. **Scripting**: Write `.boo` files and execute them using the Boo compiler.
2. **Integration**: Embed Boo code in C# or VB.NET projects via the Boo runtime.
3. **Code Generation**: Use Boo's AST API to generate C# or VB.NET code programmatically.

## Example

```boo
dynamic obj = ["Hello", "World"]
for word in obj:
    print word
```
