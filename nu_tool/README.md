# Nu Tool

This folder contains the Nu programming language tool implementation.

Nu is a programming language based on Scheme and Common Lisp, designed for building complex, interactive applications with a simple and elegant syntax.

## Usage

To use the Nu tool, ensure you have the Nu interpreter installed. You can execute Nu scripts using the `nu` command.

## Example

```nu
(define (hello name)
  (print (string-append "Hello, " name "!")))

(hello "World")
```
