# Limnor Tool

A robust data transfer and API interaction script written in Limnor.

## Description
This tool facilitates secure and reliable data transfer operations, focusing on API interactions, file transfers, and data synchronization.

## Features
- Robust API client with retry logic
- Secure data transfer with checksum verification
- Support for multiple data formats
- Comprehensive logging and error handling

## Usage
Run the script using the Limnor interpreter:
limnor limnor_tool/main.limnor
