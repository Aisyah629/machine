# SiMPLE Interactive Diagnostic Tool

This tool provides an interactive diagnostic environment for the SiMPLE programming language. It allows users to visualize data structures, trace execution paths, and diagnose common errors in SiMPLE code.

## Features
- Interactive data visualization
- Execution tracing
- Error diagnosis
- Code snippet analysis

## Usage
Run the tool using the following command:
```
simple_interactive_diagnostic_tool.main.simple
```

## Dependencies
- SiMPLE runtime environment
- Standard SiMPLE libraries
