# Snowball Interactive Diagnostic Tool

This tool provides an interactive diagnostic environment for Snowball programs, enabling users to inspect variables, track execution flow, and visualize data structures.

## Features

- Interactive variable inspection
- Execution step tracing
- Basic data structure visualization
- Error detection and reporting

## Usage

1. Load a Snowball script
2. Run the diagnostic tool
3. Monitor execution and inspect state changes
