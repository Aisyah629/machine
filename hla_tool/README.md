# HLA Tool

This tool is a High Level Assembly (HLA) compiler and interpreter wrapper.

## Description

High Level Assembly (HLA) is a high-level assembly language that provides a more readable and maintainable way to write assembly code while still offering direct hardware access and low-level control. This tool facilitates the creation, compilation, and execution of HLA programs.

## Usage

Place your `.hla` source files in this directory and run the tool to compile and execute them.

## Features

- Compiles High Level Assembly code to machine code.
- Supports standard HLA syntax and libraries.
- Provides error reporting and debugging information.

## Dependencies

- HLA Compiler
- NASM or MASM Assembler (depending on target platform)
