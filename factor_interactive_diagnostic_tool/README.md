# Factor Interactive Diagnostic Tool

This tool provides an interactive diagnostic environment for the Factor programming language. 
It allows developers to run code snippets, inspect memory usage, and diagnose common errors in a controlled environment.

## Features
- Interactive REPL-like interface
- Memory usage diagnostics
- Error diagnosis and reporting

## Usage
To use this tool, run the following command in your terminal:

```bash
factor_interactive_diagnostic_tool.factor
```

Ensure that you have the Factor programming language installed on your system.
