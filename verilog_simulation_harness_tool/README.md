# Verilog Simulation Harness Generator

## Overview
This tool is a comprehensive digital circuit verification and simulation harness generator. It automatically creates reusable testbench templates for complex FPGA architectures, streamlining the verification workflow for Verilog designs.

## Features
- Automated testbench generation based on module interfaces
- Reusable verification templates for various digital circuits
- Support for complex FPGA architectures
- Integration with popular Verilog simulators

## Usage
1. Navigate to the tool directory
2. Run the main Verilog simulation script
3. Provide the target module and interface specifications
4. Generate the verification harness

## Files
- `main.v`: Main Verilog simulation harness generator
