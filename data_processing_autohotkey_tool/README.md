# Data Processing AutoHotkey Tool

A specialized AutoHotkey utility designed for efficient data processing tasks.

## Features

- CSV Data Parsing
- Data Transformation
- Text Cleaning
- Report Generation

## Usage

1. Ensure AutoHotkey v2 is installed on your system.
2. Run the script `main.ahk`.
3. Follow the on-screen prompts to load your data file.
4. Select the desired processing operation.
