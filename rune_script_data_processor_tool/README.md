# Rune Script Data Processor Tool

This tool is designed for processing data using RuneScript. It reads input files, parses data, and prepares it for further transformation or analysis.

## Features
- Reads CSV-like formatted files
- Parses key-value pairs
- Structured data handling with HashMaps
- Extensible for complex data transformations

## Usage

```bash
./rune_script_data_processor_tool <input_file>
```

## Project Structure
- `main.rs`: Core logic for data processing
- `README.md`: This file
