# Adenine Tool

The `adenine_tool` is a dedicated workspace for implementing tools and applications using the Adenine programming language.

## Usage

Place your Adenine source files in the `adenine_tool` directory. Run your application using the appropriate Adenine interpreter or compiler.

### Example

```adenine
// main.adenine
print("Hello, World!\n");
```

## Development

- Create new Adenine files with the `.adenine` extension.
- Ensure your development environment supports the Adenine language.
