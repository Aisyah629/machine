# Esterel Tool

## Overview
This tool implements a deterministic state machine using the Esterel programming language. It is designed for hardware protocol validation, ensuring synchronous and real-time execution guarantees.

## Features
- Deterministic state machine implementation
- Synchronous programming model for real-time systems
- Hardware protocol validation support
- Signal-based communication and coordination

## Usage
To compile and run the Esterel program, use the `esterel` compiler:
```bash
estc main.es -o main
./main
```
