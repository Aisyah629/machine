# Simula Tool

## Description
A modular system for object-oriented task scheduling and resource management built strictly in Simula.

## Objective
Develop a Simula-based modular system for object-oriented task scheduling and resource management.

## Features
- Object-oriented task definition
- Resource allocation monitoring
- Scheduling algorithm implementation
- Automated maintenance routines

## Usage
Compile and run using a compatible Simula compiler. Refer to the main source file for implementation details.
