# S-Lang Tool

This folder contains the S-Lang implementation of a complex mathematical algorithm.

## Algorithm

This implementation focuses on **AES-128**, the Advanced Encryption Standard with a 128-bit key. AES is a symmetric-key block cipher widely used for secure data transmission.

## Features

- AES-128 Encryption
- S-Box Substitution
- Key Expansion
- Round Key Addition

## How to Run

Run the script using the S-Lang interpreter:

```bash
s-lang main.sl
```
