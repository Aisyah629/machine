# Octave Analysis Tool

This tool provides Octave scripts for signal processing and filtering.

## Usage

To run the signal processing script, execute the following command in your Octave environment:

```
octave main.m
```

## Features

- **Signal Generation**: Create sample signals for testing.
- **Filtering**: Apply low-pass, high-pass, and band-pass filters.
- **Visualization**: Plot signals before and after filtering.

## Code Structure

- `main.m`: Main script for signal processing and filtering.

## Dependencies

- GNU Octave
