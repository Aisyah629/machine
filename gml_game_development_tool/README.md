# Game Maker Language Tool

This tool provides a complete framework for building cross-platform 2D games using Game Maker Language (GML). It includes an event-driven core, asset pipeline utilities, and runtime execution support.

## Features
- Event-driven game loop and state management
- Sprite, sound, and room handling utilities
- Built-in physics and collision detection helpers
- Asset loading and caching system
- Debugging and profiling hooks

## Structure
- `main.gml`: Core engine initialization and event routing
- `assets/`: Placeholder directory for game resources
- `scripts/`: Utility and helper scripts
- `events/`: Event handler definitions

## Usage
1. Copy the tool into a GameMaker Studio project.
2. Ensure all scripts are placed in the appropriate script directories.
3. Initialize the engine via `gml_core_init()` in a room start event.
4. Define game objects and events using the provided event templates.
