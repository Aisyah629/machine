# Franz Lisp Expert System Shell

This tool implements an expert system shell using Franz Lisp. It provides backward chaining inference, dynamic rule loading, and fact base management capabilities.

## Features

- **Backward Chaining Inference:** Starts from a goal and works backward to find supporting facts.
- **Dynamic Rule Loading:** Rules can be loaded and updated at runtime.
- **Fact Base Management:** Supports adding, removing, and querying facts.

## Usage

To use the expert system shell, load the main Franz Lisp file and start defining rules and facts.

## Code Structure

- `main.frz`: The main Franz Lisp script containing the expert system shell implementation.
