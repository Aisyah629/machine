# Modelica Tool

This directory contains the implementation for a tool built strictly using the Modelica programming language. Modelica is a domain-specific modeling language designed for complex cyber-physical systems, enabling equation-based modeling and simulation.

## Features
- Equation-based modeling
- Support for complex physical systems (mechanical, electrical, thermal, control)
- High-fidelity simulation capabilities

## Usage
Run the Modelica simulation using your preferred Modelica environment (e.g., Dymola, OpenModelica, JModelica) by loading the main source file `main.mo`.
