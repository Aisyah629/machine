# c_string_tool

## Overview

This tool implements a high-performance string manipulation and parsing library written strictly in C. It provides optimized functions for common string operations, including search, replace, split, join, and substring extraction.

## Features

- Optimized string search algorithms (KMP, Boyer-Moore)
- In-place string modification
- Memory-efficient substring extraction
- Safe string concatenation and joining
- Null-terminated string support

## Usage

Compile the tool with a C compiler:

```bash
gcc -o c_string_tool main.c -O2
```

Run the tool:

```bash
./c_string_tool
```
