# TADS Interactive Fiction Tool

## Overview
This tool provides a comprehensive environment for creating, testing, and running interactive fiction and text-based adventure games using **TADS (The Adventures in Directional Storytelling)**.

## Capabilities
- Dynamic object-oriented parsing engine
- Rich narrative generation and state management
- Inventory and room-based exploration mechanics
- Built-in development environment for prototyping and testing

## Usage
1. Place your TADS source code (`.t` or `.adv` files) in the `src/` directory.
2. Compile the game using the provided build script.
3. Run the interpreter to play or debug your adventure.

## File Structure
- `main.t`: Core game engine and initialization logic.
- `README.md`: This documentation file.

## Note
Always ensure strict adherence to the TADS programming language specification for optimal performance and compatibility.
