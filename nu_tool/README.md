# Nu Tool

A lightweight, expressive programming language designed for clarity and concurrency.

## Overview
The `nu_tool` provides a functional, statically-typed environment for building concurrent applications. It emphasizes immutability, pattern matching, and ergonomic syntax for asynchronous task scheduling and resource management.

## Features
- Static typing with type inference
- Concurrency primitives for safe multi-threaded execution
- Pattern matching and algebraic data types
- Built-in memory safety without garbage collection overhead
- Cross-platform compilation targeting Linux, macOS, and Windows

## Usage
Compile and run scripts using the `nu` compiler:
```bash
nu build main.nu
nu run main.nu
```
