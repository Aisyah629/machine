# DIBOL Data Processor Tool

A robust, legacy-compatible data processing utility built exclusively using DIBOL. This tool provides structured record manipulation, field extraction, validation, and formatted output generation for mainframe-adjacent datasets.

## Features
- Sequential file I/O with record-level control
- Field extraction and transformation
- Data validation and error logging
- Formatted report generation
- Pure DIBOL implementation (no external dependencies)

## Usage
Compile and run using the DIBOL compiler suite. Execute the main program to process the input dataset defined in the configuration.

## Structure
- `main.dib` - Core processing logic, I/O handling, and validation routines
