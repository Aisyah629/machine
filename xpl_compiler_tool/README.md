# XPL Compiler Tool

## Overview
The XPL Compiler Tool is a portable cross-language compiler infrastructure and semantic analysis engine designed for educational purposes. It demonstrates the core principles of compiler construction using the XPL (eXperimental Programming Language) paradigm.

## Features
- **Portable Compiler Infrastructure**: Core components designed to be adaptable across different target architectures.
- **Semantic Analysis Engine**: Validates syntax trees for logical consistency and type correctness.
- **Educational Focus**: Designed with clear documentation and modular components for teaching compiler design.

## Usage
To execute the semantic analysis engine, run the main implementation script located in this directory.

## Project Structure
- `main.xpl`: The core implementation of the compiler infrastructure and semantic analyzer.
- `README.md`: This file, containing project documentation.
