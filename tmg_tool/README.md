# TMG Parser Generator Tool

## Overview
A high-performance parser generator built strictly using the TMG (Translator and Generator) language. This tool automates the construction of lexical analyzers and syntactic parsers from user-defined context-free grammars.

## Features
- Automatic grammar compilation to efficient parsing routines
- Support for recursive descent and LALR parsing strategies
- Integrated token stream generation for lexer construction
- Error recovery and detailed diagnostic reporting

## Usage
1. Write your grammar definition in a `.tmg` file.
2. Run the `tmg_tool` executable to generate the parser.
3. Link the generated code with your application.

## Project Structure
- `main.tmg`: Core grammar definition and parser generation logic.
- `README.md`: This documentation file.
