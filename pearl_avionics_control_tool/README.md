# Pearl Avionics Control Tool

A safety-critical, real-time avionics flight control simulation engine built strictly using the PEARL programming language.

## Features
- **Sensor Data Fusion**: Models and processes multiple sensor inputs with deterministic timing.
- **Timing Constraint Validation**: Verifies real-time scheduling constraints and deadlines.
- **State Transition Logging**: Generates deterministic, auditable logs for state changes.
- **Optimized Task Scheduling**: Implements real-time task prioritization and resource allocation.

## Prerequisites
- PEARL compiler or environment.
- Real-time simulation framework (if applicable).

## Usage
1. Compile the PEARL source files using the PEARL compiler.
2. Run the simulation engine with the specified configuration files.
3. Review the generated state-transition logs and timing validation reports.

## Files
- `main.pearl`: The main entry point for the avionics control simulation engine.
