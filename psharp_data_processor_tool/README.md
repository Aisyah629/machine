# P# Data Processor Tool

## Overview
This is a data processing utility written in P#. It is designed to parse, validate, and transform structured data inputs efficiently.

## Features
- **Data Parsing**: Reads input data from standard streams or files.
- **Validation**: Checks data integrity against defined schemas.
- **Transformation**: Applies configurable transformation rules to the dataset.
- **Error Handling**: Robust error reporting for malformed data.

## Usage
Run the tool using the P# compiler/interpreter:
```bash
psharp psharp_data_processor_tool/main.p#
```

## Configuration
The tool looks for a default configuration file (`config.json`) in the same directory.
