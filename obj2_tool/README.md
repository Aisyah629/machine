# OBJ2 Tool

## Description
The OBJ2 tool implements a robust object-oriented runtime environment with dynamic dispatch and secure memory management.

## Usage
This tool is designed to execute OBJ2 code, leveraging dynamic dispatch and memory safety features.

## Structure
- `main.obj2`: The primary implementation file for the OBJ2 tool.

## Features
- Dynamic dispatch for method resolution.
- Secure memory management with garbage collection.
- Object-oriented paradigm support.
