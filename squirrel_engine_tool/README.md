# Squirrel Engine Tool

A lightweight and high-performance scripting engine for embedding dynamic language execution in interactive applications, games, and simulations.

## Features
- Embeddable VM for Squirrel
- Dynamic type system with value boxing
- Coroutines for cooperative multitasking
- Garbage-collected memory management
- C++ API for host application integration

## Getting Started
Compile the main Squirrel source with your preferred compiler. See `main.nut` for core VM initialization and script execution examples.
