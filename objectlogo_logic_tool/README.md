# ObjectLOGO Logic Tool

## Overview
This tool provides an interactive diagnostic and visualization environment built strictly with ObjectLOGO. It focuses on recursive logic evaluation, state tracing, and dynamic query optimization.

## Features
- Dynamic query execution and evaluation
- Visual state tracing for recursive functions
- Interactive diagnostic mode for logic debugging
- Optimized logic parsing and evaluation engine

## Usage
1. Initialize the ObjectLOGO environment.
2. Load logic rules and queries.
3. Execute queries and observe visual state traces.
4. Utilize diagnostic mode to trace evaluation steps.

## Constraints
- Strictly uses ObjectLOGO.
- No external dependencies.
- Localized in dedicated workspace folder.
