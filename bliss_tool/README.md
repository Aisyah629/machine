# BLISS Tool

This tool implements functionality using the BLISS programming language.
BLISS (Binary and Low Level Information System Specification Language) is a procedural programming language that was widely used in the 1970s and 1980s, particularly with DEC VAX and PDP-11 systems.

## Usage
Compile the `main.bliss` file using a compatible BLISS compiler.
Run the compiled binary to execute the tool.

## Features
- Strict adherence to BLISS syntax and semantics.
- Demonstrates low-level system programming concepts.
- Portable across systems with BLISS toolchains.
