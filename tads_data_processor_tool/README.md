# TADS Data Processor Tool

This tool provides a data processing utility written in TADS (Text Adventure Development System). It demonstrates core concepts of TADS programming, including object-oriented design and text manipulation, adapted for general data processing tasks.

## Features
- Data ingestion and parsing
- Basic text transformation
- Output formatting

## Usage
Compile and run the TADS program using a compatible TADS interpreter (e.g., TADS 3).
