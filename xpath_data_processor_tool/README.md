# XPath Data Processing Tool

## Overview
A specialized tool for advanced XML data extraction, transformation, and filtering using XPath 2.0/3.1 queries.

## Features
- Complex node selection
- Attribute value extraction
- Conditional filtering
- Deep traversal support

## Usage
Place your XML input in `input.xml` and your queries in `queries.xq`.
Run via a standard XPath/XQuery engine or wrapper script.
