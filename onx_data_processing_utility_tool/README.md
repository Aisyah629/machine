# Onyx Data Processing Utility Tool

This tool provides utilities for data processing using the Onyx programming language.

## Features

- Load data from various sources
- Transform data structures
- Filter and map data elements
- Output processed data

## Usage

```onyx
import OnyxDataProcessingUtility;

let data = OnyxDataProcessingUtility.load("input.json");
let processed = OnyxDataProcessingUtility.transform(data);
OnyxDataProcessingUtility.output(processed, "output.json");
```
