# Interactive Modelica Diagnostic Tool

## Overview
This is an interactive diagnostic and visualization tool built with Modelica. It simulates a dynamic system and provides real-time diagnostics, visualizing state variables over time.

## Features
- Real-time state variable monitoring
- Diagnostic thresholds and alerts
- Visual plotting of simulation data
- Configurable system parameters

## Usage
1. Compile the Modelica model using a compatible Modelica environment (e.g., Dymola, OpenModelica).
2. Run the simulation.
3. Observe the diagnostic plots and threshold alerts.

## Code
The main Modelica code is provided in `main.mo`.

## Requirements
- Modelica-compliant simulation software
