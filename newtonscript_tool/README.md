# NewtonScript Tool

## Description
A comprehensive tool for developing, testing, and deploying NewtonScript applications on the Newton OS platform.

## Features
- Syntax highlighting and code completion
- Simulated Newton environment for testing
- Object persistence framework for managing device data
- Handwriting recognition engine integration

## Usage
To build and run a NewtonScript tool:
```bash
./newtonscript_tool/build.sh
```
