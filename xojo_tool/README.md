# xojo_tool

## Overview
The `xojo_tool` is a Rapid Application Development (RAD) tool designed to generate cross-platform desktop application boilerplate using the Xojo programming language. It focuses on creating the core structure for Windows, macOS, and Linux applications.

## Features
- Generates Xojo project file structures.
- Creates basic UI layouts for cross-platform consistency.
- Includes standard event handling templates for window load and close events.

## Usage
1. Navigate to the `xojo_tool` directory.
2. Run the main script to generate a new project skeleton.

## File Structure
- `README.md`: This file.
- `main.xojo`: The core script for generating project files.
