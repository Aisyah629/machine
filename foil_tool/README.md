FOIL (First Order Inductive Learning) Tool

This tool implements the FOIL (First Order Inductive Learning) algorithm for learning first-order logic Horn clauses.

## Features
- Learns Horn clauses from background knowledge and examples
- Supports both relational and propositional FOIL variants
- Outputs learned rules in a readable format

## Usage
Place your training examples and background knowledge in the main.foil file and run the FOIL interpreter.
