# Object Pascal Desktop Framework Tool

This tool provides a minimal, cross-platform desktop application framework written in Object Pascal (Delphi syntax). It demonstrates window creation, event handling, and basic UI rendering without relying on heavy VCL or FireMonkey frameworks.

## Features

- Lightweight window manager
- Basic widget support (Button, Label, TextBox)
- Event-driven architecture
- Cross-platform compilation support (Lazarus/LCL compatible)

## Usage

Compile using `fpc` or `delphi`:

```bash
fpc main.pas
```

Run the executable:

```bash
./main
```

## Requirements

- Free Pascal Compiler (FPC) >= 3.0
- Lazarus Component Library (LCL) for GUI support
