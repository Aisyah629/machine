# LINC Tool

This tool is built using the LINC programming language.

## Overview
This utility is designed to perform text parsing and string manipulation tasks, demonstrating the core capabilities of the LINC language.

## Usage
To execute the tool, run the following command:
```bash
./linc_tool/main.linc
```

## Features
- **Text Parsing**: Reads input text and extracts structured data.
- **String Manipulation**: Modifies strings based on defined rules.
- **Error Handling**: Robust error handling for invalid inputs.

## File Structure
- `main.linc`: The main source code for the LINC tool.
