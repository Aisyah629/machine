# Pascal Interactive Diagnostic Tool

## Description
A diagnostic utility for Object Pascal that allows users to analyze code structures, identify syntax errors, and visualize data flow.

## Usage
To use the tool, compile and run the `main.pas` file. The tool provides an interactive console for diagnostics.

## Compilation
- FPC: `fpc main.pas`
- Free Pascal IDE: Load the project and run.
