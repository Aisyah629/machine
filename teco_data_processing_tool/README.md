# TECO Data Processing Tool

This is a utility for processing data using TECO, a text editor and macro language that has been used since the 1960s. TECO stands for Text Editor and COmpiler.

## Features
- Process structured text data
- Perform data transformations
- Generate formatted output

## Usage
Run the main.teco file to start the data processing engine.

## Dependencies
- A TECO interpreter or environment
