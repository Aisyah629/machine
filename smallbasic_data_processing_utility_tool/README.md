# Small Basic Data Processing Utility Tool

## Overview
This tool is a Small Basic utility designed for lightweight data processing tasks. It is intended for environments where Small Basic is available or for educational purposes.

## Features
- Read text data from files
- Parse basic CSV-like structures
- Perform simple data transformations
- Write processed data back to files

## Usage
1. Copy the `main.sb` file to your Small Basic library.
2. Run the script in the Small Basic IDE.
3. Provide the required input file path and output file path.

## Dependencies
- Small Basic IDE
