# Pict Tool

## Overview
Pict is a visual programming language designed for creating graphical program structures and layout designs. This tool provides a comprehensive environment for visual scripting, allowing users to build complex logic through intuitive visual nodes and connections.

## Features
- Visual node-based programming interface
- Graphical layout design tools
- Interactive diagram generation
- Drag-and-drop functionality
- Real-time preview of graphical output
- Export to various graphical formats

## Usage
To use this tool, navigate to the pict_tool directory and execute the main.pict file:

```bash
python pict_tool/main.pict
```

## Structure
- `main.pict`: The core visual scripting environment script
- `README.md`: This documentation file

## Dependencies
Pict is a standalone visual programming language and does not require external dependencies beyond the Pict interpreter.

Contributions are welcome! Please ensure all visual scripts follow the established node structure and connect properly.
