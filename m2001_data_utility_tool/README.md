# M2001 Data Utility Tool

This is a comprehensive data processing utility written in the M2001 programming language. It provides functions for file I/O, data transformation, aggregation, and error handling.

## Features
- File Input/Output handling
- Data transformation and manipulation
- Statistical aggregation
- Modular design

## Usage
1. Copy the `main.m2001` file to your M2001 runtime directory.
2. Ensure your data files are in a compatible format.
3. Execute the tool to process data according to the defined functions.
