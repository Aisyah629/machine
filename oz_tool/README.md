# Oz Tool

A multi-paradigm language tool focused on constraint programming and distributed systems.

## Overview

Oz is a general-purpose programming language that supports multiple programming paradigms, including constraint programming, object-oriented programming, and functional programming. This tool provides a framework for developing constraint-based scheduling systems with distributed constraint propagation.

## Features

- **Constraint Programming**: Leverage Oz's powerful constraint solver for complex optimization problems.
- **Distributed Systems**: Support for distributed constraint propagation across multiple nodes.
- **Multi-paradigm**: Utilize functional, object-oriented, and declarative paradigms within a single framework.
- **Scheduling**: Specialized tools for resource allocation and task scheduling.

## Getting Started

To get started with the Oz Tool, follow these steps:

1. Install Oz on your system.
2. Clone this repository.
3. Run the `main.oz` file to initialize the tool.
4. Follow the examples provided in the documentation to implement constraint-based scheduling.

## Documentation

For detailed documentation and examples, refer to the [Oz Manual](http://www.mozart-oz.org/manual/).
