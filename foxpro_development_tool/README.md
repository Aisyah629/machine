# FoxPro Development Tool

This tool provides a comprehensive FoxPro development environment within the workspace. It is designed to streamline FoxPro scripting, debugging, and deployment workflows while maintaining strict adherence to the language's native paradigms.

## Features
- Native FoxPro syntax validation and linting
- Automated form and report generation scaffolding
- Database connectivity helpers for dBASE and SQL interfaces
- Integrated debugging breakpoints and variable inspection
- Localized error handling and logging

## Usage
Place your FoxPro scripts inside this directory or use the provided commands to scaffold new `.prg`, `.frx`, or `.dbf` structures. The tool operates strictly in FoxPro and does not require external runtime dependencies.

## Notes
- Always save files with `.prg` extensions for standard programs.
- Use `.frx` for form resources and `.dbf` for table definitions.
- Ensure local database paths are correctly configured for deployment.
