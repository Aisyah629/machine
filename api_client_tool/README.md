# API Client Tool

This tool is a robust data transfer or API interaction script written in **Ch**. It provides functions to perform HTTP requests (GET, POST, PUT, DELETE) with support for headers, query parameters, and JSON payloads.

## Features
- Send HTTP requests to any endpoint
- Handle JSON data encoding and decoding
- Manage custom headers
- Simple error handling

## Usage
Compile with `ch` and run the script to interact with APIs.
