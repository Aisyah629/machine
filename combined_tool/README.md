# Combined Programming Language (CPL) Memory and Network Simulator

## Overview
This tool implements a low-level memory management and network protocol simulator using the Combined Programming Language (CPL). It demonstrates fundamental concepts of memory allocation, pointer arithmetic, and network message simulation.

## Features
- Manual memory block allocation and deallocation.
- Simulated packet fragmentation and reassembly.
- Circular buffer implementation for network traffic.
- Error handling for invalid memory access and protocol violations.

## Usage
To run the simulator, compile and execute the `main.cpl` file using a CPL-compatible interpreter or compiler.
