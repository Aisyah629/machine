# PL/M String Processor Tool

## Overview
A dedicated tool for string manipulation, formatting, and processing built STRICTLY using the exact programming language: PL/M. This utility is designed for legacy system integration and low-level text operations on embedded environments where PL/M is the native runtime.

## Features
- High-performance string tokenization
- ASCII character set validation and conversion
- Buffer overflow protection with fixed-size memory pools
- Compatible with Intel 8080/8085/Z-80 architectures
- Lightweight footprint for resource-constrained systems

## Usage
1. Compile the main source file using a PL/M compiler (e.g., PL/M-80 or modern transpilers).
2. Link against standard runtime libraries.
3. Execute within a compatible microcontroller or CP/M environment.

## Directory Structure
- `main.plm` - Core implementation
- `README.md` - This documentation file

## Dependencies
- Standard PL/M compiler
- Target architecture: Intel x80 series (8080, 8085, Z-80)
