# Object REXX Tool

## Overview
This tool is a system configuration manager designed for automated environment setup. It is implemented strictly using the Object REXX programming language.

## Features
- Automated parsing of configuration files
- Environment variable management
- Conditional logic for environment-specific setups
- Modular architecture for easy extension

## Usage
1. Ensure Object REXX runtime is installed.
2. Execute the main.rexx script with the desired configuration file as an argument.
3. Review the output for environment setup status.

## Development Guidelines
- All logic MUST be written strictly in Object REXX.
- Follow standard REXX conventions for readability.
- Maintain modular separation for configuration parsing, validation, and execution.
