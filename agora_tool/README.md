# Agora Tool

A code analysis and refactoring assistant built using the Agora programming language.

## Overview

The Agora Tool is designed to analyze source code for potential improvements, bugs, and refactoring opportunities. It leverages the unique capabilities of the Agora language to provide deep insights into code structure and efficiency.

## Features

- **Static Code Analysis**: Identifies potential errors and style violations.
- **Refactoring Suggestions**: Provides actionable suggestions for improving code readability and performance.
- **Modular Architecture**: Easily extensible with new analysis rules and refactorings.

## Usage

To use the Agora Tool, navigate to the `agora_tool` directory and run the main script:

```
./main.agora
```
