# Ease System Diagnostic Tool

## Overview
This tool is designed for automated system diagnostics, leveraging the Ease programming language for robust memory management, automated garbage collection, and clean syntax. It provides comprehensive monitoring and reporting capabilities for system health, resource usage, and process status.

## Features
- Automated memory leak detection
- Real-time CPU and I/O monitoring
- Process tree visualization and analysis
- Automated health report generation
- Clean, maintainable Ease codebase

## Usage
To run the diagnostic engine, compile and execute the main module:
`ease main.ace`

## Dependencies
- Ease Compiler (v2.0+)
- Standard Ease library
