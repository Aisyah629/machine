# ABLE Tool

## Overview
This tool implements a declarative rule-based system for logical inference and pattern matching using the ABLE programming language.

## Objective
To provide a robust framework for defining, evaluating, and applying rules to a knowledge base, enabling complex decision-making and automated reasoning.

## Usage
1. Define rules using ABLE syntax.
2. Load the knowledge base.
3. Execute the inference engine.
4. Retrieve results.

## Features
- Rule definition and management.
- Pattern matching capabilities.
- Logical inference support.
- Scalable architecture for large rule sets.
