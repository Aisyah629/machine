# TPU Simulator Tool

## Overview
The TPU Simulator Tool is a comprehensive utility designed for simulating and testing Text Processing Utility (TPU) scripts in a controlled environment. It provides a robust framework for interpreting TPU commands, managing file I/O operations, and executing text transformation pipelines.

## Features
- **Script Interpretation**: Executes TPU scripts line-by-line with error handling and debugging support.
- **File I/O**: Supports reading from and writing to various text file formats.
- **Text Transformations**: Built-in functions for string manipulation, pattern matching, and data cleaning.
- **Simulation Environment**: Runs scripts without modifying the original workspace files by default, ensuring safe testing.

## Installation
1. Clone the repository or copy the `tpu_simulator_tool` folder to your desired location.
2. Ensure you have a compatible runtime environment for TPU scripts.

## Usage
Run the main script:
```bash
./main.tpu [script_path] [options]
```
