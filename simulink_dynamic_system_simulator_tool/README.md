# Simulink Dynamic System Simulator Tool

This tool is designed for simulating and analyzing dynamic systems using Simulink models. 

## Features
- Dynamic System Modeling
- Real-time Simulation
- Signal Analysis
- Performance Visualization

## Usage
1. Open the `main.slx` file in MATLAB/Simulink.
2. Configure the block parameters as needed.
3. Run the simulation to observe system behavior.
4. Use the provided logging blocks to analyze signals.

## Dependencies
- MATLAB
- Simulink
- Control System Toolbox (optional)
