# OPS5 Data Extraction and Parsing Utility

## Overview
This tool implements a basic data extraction and parsing utility using OPS5 (Production System Language). OPS5 is an AI language designed for expert systems, based on the pattern-matching rule engine concept. This utility demonstrates how OPS5 can be used to parse and extract structured data from unstructured text.

## Features
- Pattern matching for data extraction
- Rule-based parsing
- Production system architecture

## Usage
Load the production rules and input data into the OPS5 environment, then run the forward-chaining inference engine.

## Example
Rules will match patterns in the input data and extract relevant information.

## Installation
Requires an OPS5 interpreter or implementation to run.
