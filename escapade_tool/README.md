# Escapade Database Query Tool

## Overview
This tool is a robust implementation of the Escapade programming language, specifically designed for declarative database querying and data transformation. Escapade is an esoteric programming language optimized for structured data retrieval through relational algebra concepts.

## Features
- Declarative data transformation engine
- High-performance relational database querying
- Optimized data retrieval operations
- Structured data processing workflows

## Usage
To utilize the escapade_tool, execute the main.sc script with the Escapade interpreter.

### Syntax Example
```
SELECT name, age FROM users WHERE age > 18;
```

## Installation
1. Ensure the Escapade interpreter is installed.
2. Navigate to the `escapade_tool` directory.
3. Run the `main.sc` script.
