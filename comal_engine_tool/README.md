# COMAL Engine Tool

## Overview
The COMAL Engine Tool is a dedicated environment for developing, testing, and executing programs written in COMAL (Common Algorithmic Meta-Language). COMAL is a high-level, procedural programming language from the 1970s/80s, originally designed for microcomputers. It combines structured programming features of BASIC with the clarity of Pascal.

## Features
- **COMAL Interpreter/Compiler**: Executes standard COMAL syntax and commands.
- **Structured Programming Support**: Implements `IF...THEN...ELSE`, `CASE`, `WHILE`, `REPEAT...UNTIL`, and `FOR` loops.
- **Modular Development**: Supports `MODULE` and `ENDMODULE` blocks for reusable code.
- **Variable Management**: Handles dynamic typing and scope rules defined in COMAL standards.

## Usage
To use this tool, place your COMAL source code in the `main.comal` file or within the source directory.
```bash
# Run the COMAL engine tool
./run_comal_engine main.comal
```
