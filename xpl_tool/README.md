# XPL Tool

## Description
This tool is a core XPL compiler prototype designed for educational purposes and legacy system analysis. XPL (eXtended Programming Language) was a high-level, portable programming language developed in the 1970s. This prototype aims to demonstrate XPL's syntax and structure for modern learners.

## Objective
The primary objective is to develop a functional compiler prototype that can translate XPL source code into a simplified intermediate representation or a target architecture assembly, focusing on educational clarity and legacy compatibility analysis.

## Features
- Lexical Analysis: Tokenizes XPL source code.
- Syntax Analysis: Parses tokens into an abstract syntax tree (AST).
- Semantic Analysis: Checks for type consistency and variable declarations.
- Code Generation: Generates pseudo-assembly or a simplified intermediate representation.

## Usage
To use this tool, place your XPL source code files in the designated input directory and run the compiler script.
