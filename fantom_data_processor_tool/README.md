# Fantom Data Processor Tool

A high-performance data processing utility built using the Fantom programming language.

## Features
- Efficient data ingestion and transformation
- Built-in Fantom collections and streams for processing
- Configurable processing pipelines
- Robust error handling and logging

## Usage
Run the tool using the Fantom runtime:

```
fantom main
```

## Configuration
Edit the configuration settings within the `main.fan` file or use environment variables as supported.
