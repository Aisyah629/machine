# Scratch Data Processor Tool

This tool provides a modular framework for processing data blocks within the Scratch environment. It includes utilities for sorting, filtering, and transforming lists of data items.

## Features
- List Sorting (Bubble Sort implementation)
- Data Filtering based on conditions
- Item Transformation utilities
- Data Validation

## Usage
Import the `scratch_data_processor_tool.sb3` project into the Scratch editor. Use the provided custom blocks to process your data lists.
