# chapel_tool

A Chapel-based concurrent task scheduler for multi-core systems.

## Objective

Develop a concurrent task scheduler for multi-core systems using the Chapel programming language, focusing on efficient parallelism and task distribution.

## Features

- Concurrent task scheduling
- Multi-core system optimization
- Parallel execution of tasks
- Resource management and load balancing

## Usage

1. Build the tool using Chapel's compiler (`chpl`).
2. Run the executable with appropriate arguments.
