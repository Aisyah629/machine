# Icon Data Processor Tool

This utility is designed for efficient data processing tasks using the **Icon Programming Language**. It demonstrates how to parse, transform, and validate structured data (e.g., CSV/TSV) using Icon's powerful string manipulation and generator capabilities.

## Features
- Robust parsing of delimited text files.
- Data validation and transformation pipelines.
- Clean, functional code structure leveraging Icon generators.

## Usage
To execute this tool, run the following command in your terminal:

```bash
icon main.icn
```

## Structure
- `README.md`: This file.
- `main.icn`: The main logic for data processing.
