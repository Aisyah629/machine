# PILOT Text Cleaning Tool

This tool implements a dataset cleaning and text formatting utility using the PILOT programming language.

## Features
- Removes duplicate lines from datasets.
- Normalizes whitespace (leading/trailing spaces).
- Converts text to uppercase for standardization.
- Supports simple pattern-based replacements.

## Usage
Run the script with an input dataset file to process and clean the text.
