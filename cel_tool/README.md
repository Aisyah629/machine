# Cel Tool

This is the **Cel** programming language tool. Cel is a domain-specific language designed for building secure, high-performance smart contracts and distributed systems, developed at MIT CSAIL.

## Features

- Declarative smart contract syntax
- Automated formal verification
- Secure state management
- High-throughput transaction processing

## Usage

To execute a Cel contract:

```
cel run main.cel
```

To verify contract security properties:

```
cel verify main.cel
```
