# Processing Tool

This is a dedicated tool for Processing-based applications. It provides utilities for real-time visual data simulation and interactive generative art rendering.

## Features
- Real-time visual data simulation
- Interactive generative art rendering
- Processing language integration

## Usage
Place your Processing sketch code in `processing_tool/main.pde` and execute using the Processing IDE or command line.

## Requirements
- Processing IDE or command-line Processing environment
- Java Development Kit (JDK)
