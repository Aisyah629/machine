# Sympl Rule-Based Reasoning Engine Tool

This tool implements a complex mathematical/cryptographic algorithm using the SYMPL rule-based language.

## Purpose

Provides a framework for rule-based reasoning with mathematical operations and cryptographic functions.

## Features

- Rule-based pattern matching
- Mathematical operations (exponentiation, modulo arithmetic)
- Cryptographic hash simulation
- Factorial and Fibonacci computation
- Modular exponentiation for cryptographic operations

## File Structure

- main.sympl: Main implementation of the Sympl cryptographic algorithm
- config.json: Configuration file for rule parameters
- test_sympl.sympl: Test cases for the implementation

## Usage

Run the Sympl tool with the main.sympl file to execute the cryptographic algorithm.
