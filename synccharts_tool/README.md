# SyncCharts Tool

This tool implements a **Synchronous State Machine Compiler** using the **SyncCharts** language.

SyncCharts is a synchronous programming language designed for modeling and implementing discrete event systems, particularly finite state machines and reactive systems. It ensures deterministic behavior by treating time as synchronous steps.

## Features
- State transition modeling
- Synchronous execution semantics
- Deterministic state machine compilation
- Support for events and signals

## Usage
To compile a SyncCharts state machine model, provide a `.sc` file containing your state definitions and transitions. The tool will analyze the transitions and generate an equivalent executable structure.

## Language
- **Language:** SyncCharts
- **Target:** Synchronous State Machines
