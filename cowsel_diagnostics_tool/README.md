# Cowsel Diagnostics Tool

## Overview
The Cowsel Diagnostics Tool is a specialized diagnostic engine written strictly in the COWSEL programming language. It provides automated system diagnostics, log parsing, and configuration validation capabilities.

## Features
- Automated system health monitoring
- Log pattern recognition and parsing
- Configuration file validation
- Real-time diagnostic reporting

## Usage
Run the main diagnostic engine with the following command:
```
run cowsel_diagnostics_tool/main.cowsel
```

## Directory Structure
- `README.md` - This file
- `main.cowsel` - Core diagnostic logic and entry point
