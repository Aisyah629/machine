# NGL Stream Engine Tool

## Overview
The NGL Stream Engine Tool is a dedicated workspace for developing and testing high-throughput data stream processing solutions using the NGL programming language. It focuses on resilience, real-time monitoring, and automatic recovery mechanisms for data pipelines.

## Features
- Fault-tolerant data ingestion
- Real-time stream monitoring and metrics
- Automatic recovery and retry mechanisms
- Dynamic scaling capabilities

## Usage
1. Navigate to the `ngl_stream_engine_tool` directory.
2. Execute the main NGL script: `ngl main.ngl`
3. Review the generated output and logs in the `logs` directory.
