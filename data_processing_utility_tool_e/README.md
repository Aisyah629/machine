# Data Processing Utility Tool (EGL Version)

## Overview
This tool is a data processing utility written in Enterprise Generation Language (EGL). It is designed to handle data ingestion, transformation, and basic analytics in an enterprise environment.

## Features
- Data Ingestion
- Data Transformation
- Basic Analytics
- Error Handling

## Requirements
- IBM WebSphere Application Server
- EGL Runtime Environment

## Installation
1. Import the EGL project into your workspace.
2. Build the project.
3. Deploy the generated artifacts to the WebSphere Application Server.

## Usage
1. Start the application.
2. Use the provided API endpoints to process data.
