# FL Transformation Tool

This tool provides a declarative functional transformation engine built strictly using the FL programming language.

## Features
- High-performance functional transformations
- Declarative syntax for data manipulation
- Integration with existing FL workflows

## Usage
1. Compile the main.fl file using the FL compiler.
2. Run the executable to start the transformation engine.
3. Input your data transformation scripts in FL format.

## Files
- main.fl: The core implementation of the transformation engine.
