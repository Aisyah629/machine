# JScript Tool

## Overview
This tool provides a robust scripting engine for Windows automation and legacy system integration. It is implemented in JScript.

## Features
- Windows automation capabilities
- Legacy system integration support
- Object-oriented scripting
- COM object interaction

## Usage
Execute the main script using the Windows Script Host:

```bash
cscript jscript_tool/main.js
``` or `wscript jscript_tool/main.js` for GUI mode.
