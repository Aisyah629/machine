# VB.NET Tool

A robust data transfer and API interaction script built with Visual Basic .NET.

## Features
- RESTful API calls using HttpClient
- Authentication via Bearer token
- Error handling for network issues
- Console output for response data

## Usage
1. Set the API_KEY environment variable or modify the default key in the code.
2. Compile with `vbnc main.vb` or `dotnet run`
3. Run the compiled executable

## Notes
- Replace `baseUrl` with your target API endpoint.
- Adjust headers and request methods as needed for your specific API.
