# Id Tool

This directory contains the source code and documentation for the **Id** programming language tool. The tool is designed to parse, compile, and execute code written in the Id language, providing a robust environment for developers working with this specific programming paradigm.

## Features

- **Id Syntax Highlighting**: Full support for Id language syntax.
- **Interactive REPL**: A Read-Eval-Print Loop for real-time testing and execution of Id code.
- **Static Analysis**: Comprehensive static analysis tools to catch errors before runtime.
- **Documentation Generation**: Automatically generates documentation from Id source code comments.

## Usage

To use the Id Tool, place your source code in the `id_tool` directory and run the main script:

```bash
python main.py <input_file.id>
```
