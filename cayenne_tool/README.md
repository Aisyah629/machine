# Cayenne Tool

This tool implements a secure cryptographic protocol verifier using the Cayenne programming language.

## Features

- Verifies cryptographic protocols for security vulnerabilities
- Implements strict type checking and formal verification concepts
- Focuses on secure communication and key exchange verification

## Usage

Run the tool to analyze cryptographic protocol definitions and verify their security properties.

## Language

This project is written in Cayenne, a purely functional programming language designed for high-assurance software.
