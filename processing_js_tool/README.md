# Processing.js Tool

## Overview
This tool is a comprehensive creative coding and data visualization engine built strictly using Processing.js. It leverages the power of Processing.js to render interactive graphics and visualizations directly in web browsers.

## Features
- Interactive creative coding environment
- Real-time data visualization
- Dynamic browser rendering
- Support for Processing syntax and libraries
- Cross-browser compatibility

## Usage
To use this tool, include the Processing.js library in your HTML file and create a sketch using Processing.js syntax.

## Files
- `main.pjs`: The main Processing.js sketch file.
