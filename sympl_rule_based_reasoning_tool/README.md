# Sympl Rule-Based Reasoning Tool

## Overview
The Sympl Rule-Based Reasoning Tool is a comprehensive engine built strictly using the SYMPL programming language. It provides advanced capabilities for symbolic manipulation, pattern matching, and automated inference.

## Features
- **Rule-Based Inference**: Supports forward and backward chaining.
- **Symbolic Processing**: Handles complex logical predicates and algebraic simplifications.
- **Pattern Matching**: Advanced automated pattern matching capabilities.
- **Knowledge Base Management**: Manage dynamic knowledge bases efficiently.

## Usage
Place your SYMPL source code in the main.sympl file and run the tool to execute the reasoning engine.
