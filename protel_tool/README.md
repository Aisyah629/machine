# Protel Tool

This tool is a dedicated utility built for schematic capture and routing, developed strictly in the PROTEL programming language. It provides automated design rule checking, component placement optimization, and net tracing capabilities.

## Features
- Automated schematic capture and routing
- Design rule checking (DRC) and electrical rule checking (ERC)
- Component placement optimization
- Net tracing and connectivity analysis
- Export to industry-standard formats (IPC, Gerber)

## Usage
Run the main execution script:
```
./protel_tool/main.protel
```
