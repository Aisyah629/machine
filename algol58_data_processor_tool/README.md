# ALGOL 58 Data Processor Tool

This tool provides a functional algorithmic solution for batch data processing using ALGOL 58. 
It is designed to simulate a data pipeline that reads, transforms, and outputs records in a strict procedural format.

## Usage

Compile with a standard ALGOL 58 compiler and execute as a batch job.

## Components
- **Data Input**: Simulated via static arrays.
- **Processing**: Arithmetic transformation and filtering.
- **Output**: Standard printing of processed records.
