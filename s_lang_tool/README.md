# S-Lang Tool

This tool is built using the S-Lang programming language.

S-Lang is a programming language primarily used for scripting and automation, particularly within the context of astronomical data reduction and analysis, but also widely used for general-purpose scripting due to its powerful data handling capabilities and extensibility.

## Features

- **Scripting:** Write complex scripts for data processing and automation.
- **Interactivity:** Ideal for interactive data analysis and visualization.
- **Extensibility:** Can be extended with C code for performance-critical sections.
- **Library Support:** Access to a wide range of library functions for common tasks.

## Usage

To run the tool, ensure you have S-Lang installed on your system. Save the script as `main.sl` and execute it using the S-Lang interpreter:

```bash
slang main.sl
```
