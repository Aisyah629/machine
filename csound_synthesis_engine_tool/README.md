# Csound Synthesis Engine Tool

A dedicated tool for real-time audio synthesis and signal processing built strictly with Csound.

## Features
- Real-time audio synthesis
- Signal processing
- Customizable instrument design
- MIDI and audio I/O support

## Usage
Compile and run the Csound orchestra file using the Csound command line or GUI.

## Structure
- `main.csd`: The main Csound orchestra and score file.
