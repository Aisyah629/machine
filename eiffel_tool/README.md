# Eiffel Tool

This directory contains the source code for the Eiffel-based software engineering tool.

## Description
A dedicated utility built STRICTLY in Eiffel for automated software engineering tasks.

## Usage
Compile and run the main Eiffel source file located in this directory using the standard Eiffel compiler (`ec` or `eiffelstudio`).

## Structure
- `main.e`: Core implementation in Eiffel.
