# Combined Programming Language Data Processing Utility

## Overview
This utility is designed for data processing tasks using the Combined Programming Language (CPL). It serves as a modular tool to handle data ingestion, transformation, and output formatting.

## Features
- **Data Ingestion**: Reads data from standard input or predefined data structures.
- **Data Transformation**: Applies user-defined functions to transform data.
- **Output Formatting**: Formats processed data for output to console or files.

## Usage
1. Ensure you have the Combined Programming Language compiler installed.
2. Run the utility using the following command:
   ```
   cpl_tool main.cpl
   ```
3. Follow the prompts to input data or configure processing rules.
