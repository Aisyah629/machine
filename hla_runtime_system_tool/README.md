# HLA Runtime System Tool

## Overview
A modular system utility written in High Level Assembly (HLA) focused on process management and memory allocation debugging. This tool provides low-level introspection and control over system processes and memory, demonstrating the capabilities of HLA in system-level programming.

## Features
- **Process Management**: Enumerate and manage system processes.
- **Memory Allocation Debugging**: Monitor and debug memory allocations.
- **Modular Architecture**: Designed for easy extension and maintenance.

## Requirements
- High Level Assembly (HLA) compiler
- Windows API (or target OS equivalent) for process and memory operations

## Usage
Compile the main.hla file and run the resulting executable to start the runtime system utility.
