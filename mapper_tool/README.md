# MAPPER Tool

## Overview
This tool contains the implementation for the MAPPER programming language utility.

## Usage
See the main source file `main.mapper` for implementation details and execution instructions.

## Features
- Implements core MAPPER language syntax and semantics.
- Provides a standalone executable/utility for processing tasks within the MAPPER framework.

## File Structure
