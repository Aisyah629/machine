# Prolog Tool

## Overview
The Prolog Tool is a symbolic AI inference engine designed for logical deduction. It leverages the power of Prolog, a logic programming language, to process and reason over logical rules and facts. This tool is capable of solving complex logical problems, performing pattern matching, and executing backtracking searches to deduce solutions based on predefined knowledge bases.

## Features
- **Symbolic AI Inference**: Enables logical deduction through rule-based reasoning.
- **Knowledge Base Management**: Supports loading and managing facts and rules.
- **Backtracking Search**: Utilizes Prolog's native backtracking for exhaustive search capabilities.
- **Pattern Matching**: Efficiently matches patterns against structured data.
- **Extensible Rules**: Users can define custom rules to expand the engine's capabilities.

## Getting Started
To use the Prolog Tool, ensure you have a Prolog interpreter installed (e.g., SWI-Prolog). Save the `main.pl` file and load it into the Prolog environment.

### Example Usage
```prolog
?- consult('main.pl').
?- start_engine.
```
