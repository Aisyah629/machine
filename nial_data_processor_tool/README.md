# Nial Data Processor Tool

## Description
This tool implements a robust data processing utility using Nial, a high-level language for dataflow programming. It supports array-oriented operations, transformation, filtering, and aggregation of datasets.

## Features
- Array-oriented data processing
- Flexible transformation pipelines
- Filtering and selection capabilities
- Aggregation functions

## Usage
To use this tool, ensure Nial is installed and accessible in your environment.

### Example Data
```nial
MYDATA : [1 2 3; 4 5 6; 7 8 9]
```
