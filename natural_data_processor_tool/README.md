# Natural Data Processor Tool

## Description
This tool processes data using the NATURAL programming language. NATURAL is a 4GL language designed for high-performance data manipulation and reporting, often used with Adabas databases.

## Features
- Data reading and writing
- String manipulation
- Aggregation and filtering
- Report generation

## Usage
Run the tool with:
```bash
natural_data_processor_tool/main.nat
```
