# Spark Data Processor Tool

A SPARK (Ada for High-Assurance Systems) utility for processing and transforming datasets.

## Usage

This tool provides a framework for processing data records with strict type safety and verification contracts.

## Files

- `main.adb`: Main executable for the data processor.
- `data_processor.ads`: Public API for the data processing engine.
- `data_processor.adb`: Implementation of the data processing engine.
- `contracts.ads`: GNATprove verification contracts for the processing logic.
