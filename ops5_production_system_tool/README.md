# OPS5 Production System Tool

## Overview
OPS5 (Operating System 5) is a classic production rule system language designed for building expert systems. This tool implements a functional production rule engine capable of declarative problem-solving and state-transition modeling.

## Features
- Production Rule Engine: Matches conditions (LHS) against working memory to trigger actions (RHS).
- State-Transition Modeling: Manages complex state changes based on rule firings.
- Expert System Capabilities: Supports declarative logic for decision-making.

## Usage
Place your OPS5 production rules and working memory data into the main script file. The engine will process the rules and update the state accordingly.

## Implementation Language
This tool is built strictly using the OPS5 programming language.
