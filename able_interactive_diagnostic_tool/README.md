# ABLE Interactive Diagnostic Tool

## Description
The ABLE Interactive Diagnostic Tool provides an advanced framework for monitoring, analyzing, and visualizing program execution flows in ABLE-based systems. It supports real-time data visualization, dynamic pipeline inspection, and interactive debugging of complex algorithms.

## Features
- **Real-time Visualization:** Displays execution states and variable snapshots visually.
- **Pipeline Diagnostics:** Inspects the state of active ABLE pipelines.
- **Interactive Debugging:** Step-by-step execution with conditional breakpoints.
- **Performance Monitoring:** Tracks CPU usage and memory allocation during runs.

## Usage
1. Initialize the tool in your ABLE script using the provided library.
2. Define diagnostic points in your critical sections.
3. Run the ABLE interpreter with the diagnostic flag enabled.
4. View the console or web-based dashboard for live updates.
