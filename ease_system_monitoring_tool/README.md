# Ease System Monitoring Tool

## Overview
This tool provides a robust system monitoring solution built using the **Ease** programming language. It focuses on real-time data collection, resource tracking, and automated alerting for system health.

## Features
- **Real-time Resource Tracking**: Monitors CPU, memory, disk I/O, and network usage.
- **Automated Alerting**: Configurable thresholds trigger notifications.
- **Data Logging**: Persistent logging of system metrics for historical analysis.
- **Modular Architecture**: Easily extensible for custom monitoring tasks.

## Usage
1. Ensure the Ease compiler/runtime is installed.
2. Compile the main script: `ease main.eas`
3. Run the compiled binary: `./ease_system_monitoring_tool` or `ease ./main.eas`
