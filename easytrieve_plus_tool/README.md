# Easytrieve Plus Tool

## Overview
The `easytrieve_plus_tool` is a specialized utility designed for high-throughput mainframe data processing. It leverages the EASYTRIEVE PLUS language to handle complex record manipulation, sorting, joining, and reporting tasks efficiently.

## Features
- High-performance record processing
- Support for multiple file formats
- Advanced reporting capabilities
- Optimized for mainframe environments

## Usage
Place your EASYTRIEVE PLUS source code in `main.epl` within this directory. The tool will process the input data according to the defined logic and generate the required output reports or data sets.

## Configuration
No additional configuration is required. Ensure that your input data files are accessible in the expected directories as specified in your EASYTRIEVE PLUS program.
