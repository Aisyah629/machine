# SBL Data Processor Tool

This utility is designed to perform comprehensive data processing operations using the SmallBASIC (SBL) programming language.

## Features

- **Data Ingestion**: Read data from CSV, JSON, or plain text sources.
- **Data Transformation**: Filter, map, and aggregate datasets.
- **Data Validation**: Check for data integrity and type consistency.
- **Output Generation**: Write processed data to specified formats.

## Usage

1. Clone or copy this directory into your project workspace.
2. Open `main.sb` using a SmallBASIC interpreter.
3. Run the script to process the default dataset located in the directory.

## Configuration

You can configure file paths and processing options directly in the `config` block within `main.sb`.

## Requirements

- SmallBASIC (or any compatible SBL interpreter)
