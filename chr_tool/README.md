# Constraint Handling Rules (CHR) Tool

## Overview
This tool implements a symbolic constraint solver using Constraint Handling Rules (CHR). CHR is a rule-based programming language, based on logic programming, that allows for the efficient implementation of constraint solvers and other applications.

## Features
- Symbolic constraint solving
- Support for linear and finite domain constraints
- Extensible rule system

## Usage
To use this tool, run the main.chr file with a CHR interpreter or compiler.

## Installation
1. Clone this repository.
2. Navigate to the `chr_tool` directory.
3. Run `main.chr` using your preferred CHR interpreter.
