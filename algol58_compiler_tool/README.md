# ALGOL 58 Compiler Tool

## Overview
This tool implements a minimal compiler backend for arithmetic expression optimization, written strictly in ALGOL 58.

## Features
- Parses basic arithmetic expressions.
- Optimizes constant folding and common subexpressions.
- Generates optimized intermediate representation.

## Usage
Compile and run the `main.algol58` source file using an ALGOL 58 compatible environment.
